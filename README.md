# 知识库问答生成工具

面向 **RAG 知识库、培训题库、话术整理** 等场景：上传 **PDF / Word（.docx）/ Markdown / TXT** 等本地文件，程序自动 **抽文本 → 切片 → 调大模型**，批量产出可检索的 **问答对**，减轻人工逐条编写成本。

- 在本机运行 **FastAPI 后端**，浏览器访问 `http://127.0.0.1:8765` 操作（**不要**双击打开 HTML）。
- **API Key** 在浏览器页面填写使用，不会由工具自动写入服务器硬盘；请按安全规定自行保管密钥。
- **不支持** 在页面填写网页链接抓取正文，只支持 **本地上传**。

---

## 功能概览

| 组件 | 功能 |
|------|------|
| **输入** | PDF / docx / md / txt 上传与列表管理；预览提取文本，查编码与解析 |
| **多模型生成** | 配模型 ID、Key、兼容网关；多条模型依次跑同一材料便于对比 |
| **切片与调用** | 设块长、重叠、轮次与温度；可多线程并发；预览前 6 块切片 |
| **出题说明** | 六项自然语言定题型、难度、答案长度及各切片数量策略 |
| **运行与日志** | 进度条与本地日志；失败段跳过；可停止；三种格式导出 |
| **结果** | 页面展示前 100 条；完整问答对通过 JSON / CSV / MD 下载 |

### 能解决什么问题

| 痛点 | 工具如何帮助 |
|------|--------------|
| 材料很长，人工想问答很累 | 自动切块（按字数或 Markdown 标题），多轮、多模型批量调用 |
| 切片多、串行调用太慢 | 可开 **多线程并行调用 API**，设置并发数（默认 5） |
| 不同项目要不同风格 | **出题说明** 六项用自然语言写清规则，可保存复用 |
| 不确定哪个模型更适合 | 配置多条模型，**按列表从上到下串行** 跑完同一材料便于对比 |
| 网络抖动、单次报错 | **自动重试**；单段失败跳过，已生成结果保留；密钥错误通常整单停止 |
| 并发过大导致限流 | 调低并发或改回单线程；日志会提示 |
| 生成到一半想中断 | 点 **停止生成**；已返回的行通常仍可查看并导出 |
| 需要特定格式成品 | 导出 **JSON、CSV、Markdown** |

## 快速开始

### 环境要求

- **Python 3.10+**（推荐 3.12）
- 项目目录含 `main.py`、`requirements.txt`、`static/` 等
- 生成阶段需能访问您所填的模型服务；安装依赖时需能访问 PyPI（或镜像源）

### 首次安装（只做一遍）

**1. 进入项目目录**（必须能看到 `main.py`）

```bash
# Mac / Linux
cd /您的项目路径/RAG

# Windows
cd C:\您的项目路径\RAG
```

**2. 确认 Python**

```bash
# Mac / Linux
python3 --version

# Windows
py -3 --version
```

若找不到命令，请从 [python.org](https://www.python.org/downloads/) 安装，并勾选 **Add Python to PATH**，安装后重新打开终端。

**3. 创建虚拟环境**

```bash
# Mac / Linux
python3 -m venv .venv

# Windows
py -3 -m venv .venv
```

**4. 安装依赖**

```bash
# Mac / Linux
.venv/bin/pip install -r requirements.txt

# Windows
.venv\Scripts\pip.exe install -r requirements.txt
```

过程可能持续数分钟；若无明显 `ERROR` 即成功。

### 启动服务

每次使用时：

1. 打开终端，`cd` 到项目目录  
2. 执行启动命令（**不要关终端窗口**）  
3. 浏览器访问 `http://127.0.0.1:8765`

```bash
# Mac / Linux
.venv/bin/python -m uvicorn main:app --host 127.0.0.1 --port 8765

# Windows
.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8765
```

看到 **`Uvicorn running on http://127.0.0.1:8765`** 即成功。端口被占用时可将 `8765` 改为其他端口，浏览器地址同步修改。

**停止服务：** 在运行 uvicorn 的终端按 **Ctrl + C**。

### Docker 部署（可选）

项目根目录含 **Dockerfile**，可构建镜像部署，默认端口 **8765**：

```bash
docker build -t rag-qa-generator .
docker run -p 8765:8765 rag-qa-generator
```

## 界面使用指南

界面自上而下说明如下。

### 1. 全局与连接

- **未连上后端时** 页面顶部会出现黄色提示条，提示启动服务，并说明须用 `http://127.0.0.1:端口` 访问，**不要用 `file://` 双击打开 HTML**。
- **右上角**：浅色 / 深色主题切换；粒子背景仅为视觉，不影响功能。

### 2. 输入

- **支持格式**：PDF、Word（仅 .docx）、Markdown（.md / .markdown）、TXT；可多选、可多次拖拽累加。
- **已上传列表**：展示文件名、大小，可删除；显示「共上传了 X 个文档」。
- **传输进度**：预览或生成时，输入区下方出现传输进度条。
- **预览提取文本**（不调用大模型）：
  - 可设「预览最多显示字符数」或「尽量全文（上限 50 万）」；
  - 结果在「提取文本预览」区域展示，可「收起」；
  - 预览按字数截断，用于核对编码与解析；**真正生成仍使用完整提取结果**。
- 将文件拖到 **虚线框内** 添加；拖放位置不对可能导致页面报错。

### 3. 多模型生成

- **调用顺序**：严格按列表从上到下。第 1 个模型先跑完所有文档块 × 循环轮次，再跑第 2 个模型……
- **每条模型可配**：
  - **显示名称**（可选）：出现在结果表「模型」列及导出文件中。
  - **调用方式**：LLM Center / OpenAI 兼容，或 Google Gemini（官方 API）。
  - **模型 ID**、**API Key**；兼容模式下 **Base URL**、**LLM Center 多协议**（OpenAI / Anthropic / Google Gemini 原生等）。
  - 从第 2 条起：**模型 ID、Key、Base URL** 可留空，表示与第 1 条相同。
- **兼容网关鉴权**：兼容模式且协议为 OpenAI 时，可选 Bearer / api-key 头 / X-API-Key 等。

### 4. 切片与调用

控制每次送给模型的正文长度、块间重叠、轮次、温度、重试次数、max_tokens 等。卡片内「参数说明」有逐项解释。

- **单次阅读多少字**：每一块正文大约多长。
- **相邻两段重复多少字**：避免从一句话正中间切开。
- **Markdown 按标题切分**（可选）：仅对 `.md` / `.markdown` 文件名生效；可选 H1～H6 在哪一级新起一段；PDF、Word、纯 TXT 仍按字数切分。
- **同一段让模型答几轮**：同一块多跑几轮可多挖一些题。
- **创意程度（温度）**：越低越贴原文，越高越发散。
- **网络不稳时自动多试几次**：某段失败会重试，仍失败则跳过该段。
- **单次回答最长（max_tokens）**：题目很多、答案很长时可调大，避免截断。
- **多线程并行调用 API**（默认关闭）：
  - 关闭 = 单线程，按顺序逐段调用，最稳定。
  - 开启后设置 **并发数**（默认 5）；多个切片同时请求，整体更快。
  - 生效条件：开关打开 **且** 并发数 > 1 **且** 总调用次数 > 1。
  - 并行时完成顺序可能与切片顺序不一致；汇总后仍按 **模型 → 切片 → 轮次** 排序输出。
  - **多模型** 仍按模型串行：先跑完第 1 个模型的全部切片，再跑第 2 个。
  - 日志出现 **`ThreadPoolExecutor max_workers=…`** 表示并行已生效。
- **单次阅读预览**：展示按当前切片规则得到的 **前 6 块** 将送给模型的原文（与「开始生成」同源）。与「输入」区的「预览提取文本」不是同一种预览。
- **超大文档自适应**：单份提取结果超过阈值时，后端自动采用更小的片段长度，并在运行日志中说明。

### 5. 出题说明

- **六项** 多行文本：**任务形式、问题难度、答案长度、语言风格、数量策略、内容覆盖**。内容以自然语言写入，合并进每一次切片调用的 prompt。
- **数量策略**（重要）：
  - 数量约定作用在 **「每个切片」**，不是整篇文档总量。
  - 示例「本片段必须生成 30 组…」= **每个切片** 各 30 组；文档切 6 块时理论最多约 6×30 组。
  - 当前 **没有** 服务端「全文档合计截断到 N 条」的逻辑；「整篇一共 N 组」无法可靠实现。
  - 不写固定条数时，由模型按该切片内容自行决定。
- **完整 prompt**：底部折叠区「完整prompt」为 **只读**，展示内置模板（含 `{text}`、`{round}` 等占位符）；**不可编辑**，改规则请改上面六项。

### 6. 运行与日志

- **开始生成 Q&A**：需至少上传一个文档；流式反馈进度条与「本地运行日志」。
- **停止生成**：中断进行中的请求；已返回的结果通常仍保留。
- **清空日志**：仅清除日志文本，不清结果表。
- **下载 JSON / CSV / Markdown**：有结果时可导出；全量在文件中，不受页面展示条数限制。

### 7. 结果

- **表格列**：来源（文件名）｜块（切片序号）｜轮（循环轮次）｜模型｜#（问答对序号）｜问题｜答案。
- **页面展示上限**：表格 **最多显示前 100 条**；完整数据请用下载文件查看。
- **多模型**：每个模型跑完全部片段与轮次后，结果按顺序追加，每行一条问答。

## 后台行为摘要

| 环节 | 行为 |
|------|------|
| 文档解析 | PDF / docx / md / txt → 纯文本 |
| 切块 | 按「单次阅读多少字」、可选 Markdown 标题；超大文档自动缩小块长 |
| 调用顺序 | **模型串行**（模型 1 全部切片 → 模型 2 …）；**切片可并行**（若开启多线程） |
| 单次调用 | 每个「切片 × 轮次 × 模型」发一次 API；prompt 含六项出题说明 + 该切片正文 |
| 数量策略 | 写入每次调用的 prompt；约定的是 **该切片** 出多少对，非全文档合计 |
| 失败处理 | 单段重试后仍失败则跳过；API Key 错误通常整单停止 |
| 结果 | 汇总为表格行；页面最多展示 100 条，完整数据靠导出 |

## 常见问题

**浏览器里出现黄条，说连不上服务器？**  
先确认终端里启动命令仍在运行；地址必须是 `http://127.0.0.1:8765`（端口与命令一致），不要用 `file:///...` 打开本地 HTML。

**`pip install` 很慢或超时？**  
多为网络问题；可换网络、稍后重试，或配置国内 PyPI 镜像源。

**预览或生成一直失败？**  
看运行日志里的提示；核对 Key、模型 ID、Base URL、协议类型是否与网关文档一致；确认本机网络能访问该网关。

**Word 提示不支持？**  
只支持 **.docx**。老版 **.doc** 请用 Word 打开后 **另存为 → Word 文档（.docx）**。

**想多要一些问答？**  
可调大「同一段让模型答几轮」，或减小「单次阅读多少字」让块变多；也可在数量策略里写清楚 **每个切片** 出多少对。题目很多时适当调大 max_tokens 以免截断。

**开了多线程还是很慢，或报错很多？**  
看本地运行日志是否出现 `ThreadPoolExecutor`；若并发过大，请调低并发数或改回单线程。

**想整篇文档一共只要 30 组问答？**  
当前版本按切片分别调用模型，不能可靠限制全文档总量。可尝试把「单次阅读多少字」调得很大让全文变成 1 个切片（文档很长时可能失败），或生成后在导出文件里自行删减。

**`python3` 或 `py` 找不到？**  
安装 Python 并勾选加入 PATH；安装后重新打开终端再试。
